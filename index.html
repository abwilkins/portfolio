2026 · Personal Project

Home Lab NAS & Automated Backup Server

Built to merge two interests — photography and IT — into one problem worth solving: reliable access to my own files from any machine in the house.

  • Architected and deployed a NAS and automated backup server on an x86 mini PC running Debian Linux with OpenMediaVault (OMV).
  • Managed two independent 4TB EXT4 volumes mounted by immutable UUID — one shared via SMB for centralized media storage, the other configured for native Apple Time Machine backup via the vfs_fruit Samba module.
  • Migrated roughly 1.1TB of data via rsync in detached screen sessions for reliable, uninterrupted background transfers.
  • Implemented POSIX permission structures (775, root:users) and configured S.M.A.R.T. disk telemetry for proactive hardware health monitoring.
Debian Linux OpenMediaVault Samba/SMB rsync NAS S.M.A.R.T.
